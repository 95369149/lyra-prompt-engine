## 核心理念

小小东提示词的核心突破是：**让 AI 先理解词义，再推导画面，而不是直接生成画面**。

所有提示词都留足了自定义的口子，位置固定：
- 提示词主体 = 「汤底」
- 末尾追加的画面气质说明 = 「个性化美学杠杆」

**设计哲学**：
1. **词义理解优先**：先分析字面含义、情绪气质、文化联想、隐含象征
2. **视觉隐喻转化**：将抽象概念转化为具体视觉载体
3. **巨型文字骨架**：文字不是标题，而是空间结构
4. **承载面逻辑**：有地面版强调舞台/地平线/平台
5. **防退化自检**：不做普通插画、不做电商海报、不做廉价模板

### 7. GPT2 表情包自由 x 礼崩乐坏版

**推文**：https://x.com/xiaoxiaodong01/status/2048652673826869294
**文章**：https://x.com/i/article/2048（推测）
**数据**：14 回复，48 转发，208 点赞，317 收藏，23.7K 浏览
**标题**：GPT2：表情包自由 x 礼崩乐坏版 x 老抽~风 x 太通人性了

**核心特色**：
- **错误一致性**：不是“写实一致性”，而是“错得一致”
- **MS Paint鼠标乱画**：抖动、不稳定、锯齿明显，像鼠标画
- **低质量但好笑**：笨拙、直接、荒诞、好笑
- **16枚贴纸合集**：4x4排列，每个贴纸独立画面
- **图文同时生成**：不是先画图再加文字，而是同时发生

**核心机制**：
1. **一致性定义**：同一角色在不同贴纸中不需要长得一样，但必须“画得像同一个人乱画的”
2. **必须统一**：相同的笨拙画法、相同的简化方式、相同的错误习惯
3. **允许变化**：五官错位、比例变化、结构错误、细节缺失
4. **必须保留**：最低识别特征（如发型轮廓、颜色、标志物）

**输入结构**：
- 图片1：角色参考（人/动物/组合）
- 图片2：版式参考（仅用于理解16格结构）
- 用户变量：文案内容（多行文本，可少于或多于16条）

**风格DNA**：
- 线条：抖动、不稳定、锯齿明显
- 形态：比例失衡、火柴人或极简结构
- 细节：极少细节，呈现“不会画”
- 质感：像素感、边缘粗糙
- 构图：单个贴纸允许混乱，整体结构清晰
- 情绪：笨拙、直接、荒诞、好笑

**文案系统**：
- 语气优先：吐槽、自言自语、情绪爆发、敷衍/不耐烦/荒谬
- 表达目标：一眼能懂、情绪强烈、有传播感
- 避免：礼貌表达、标准回复句式

**最终目标**：生成16枚贴纸合集，效果必须像：“一个人不会画画，但用鼠标乱画了16次，每次顺手写了一句不同状态下的吐槽，结果意外很好笑。”

### 3. GPT2 抓拍视角 x 真实质感 x 纪录片情绪

**推文**：https://x.com/xiaoxiaodong01/status/2048229427906248744
**数据**：16 回复，55 转发，393 点赞，575 收藏，63.5K 浏览
**标题**：GPT2 提示词：抓拍视角 x 真实质感 x 氛围表达 x 纪录片情绪 x 细腻得可怕

**核心目标**：
- 不是摆拍写真、不是广告大片、不是电影剧照
- 像在真实生活中，摄影者恰好从合理观察位置偶然捕捉到的一瞬间
- 具有：自然、真实、非表演感、有距离感、有旁观视角、有现场感

**重要修正：主体不要太远，必须看得清**
1. 默认不要生成"大远景人物很小"的画面
2. 主体人物应足够清晰可辨认（面部轮廓、发型、穿着、手部动作）
3. 景别优先：中景、中近景、半身到膝上构图
4. 人物在画面中占比约1/3到2/3
5. 即使保留旁观感，也要让人物成为清楚视觉焦点

**视角要求**：
- 从街边、通道、站台、商场、校园、公共休息区等位置
- 以一种不打扰主体的方式
- 在正常视线高度或略带偏移的角度
- 捕捉人物处于自然状态中的一瞬间
- 人物通常不直视镜头，动作自然、松弛、生活化

### 6. GPT2 线条融一切提示词（完整爬取）

**推文**：https://x.com/xiaoxiaodong01/status/2049526865115910515
**文章**：https://x.com/i/article/2049
**数据**：8 回复，14 转发，80 点赞，114 收藏，21.6K 浏览
**标题**：GPT2: 线条的艺术 x 超强提示词 x 海报 x 封面 x 自媒体运营标配

**核心特色**：
- **抽象但有逻辑**：不是随机线条，而是围绕主题生成可解释的视觉结构
- **线条气质智能变化**：根据主题自动选择理性几何、感性流动、冲突撕裂、生物形态、手绘线稿等风格
- **多层次图形语言**：主视觉层、辅助结构层、氛围装饰层、质感层
- **高度适配性**：适合视频封面、文章头图、海报、社交媒体封面等多种用途

**设计哲学**：
1. **先理解主题**：分析表层含义、情绪气质、内在张力、语义关系
2. **再决定表达方式**：根据主题选择图形语言、线条气质、结构方式、色彩策略
3. **背景回应主题**：抽象图形应成为主题意义的延伸，不是随机装饰

**五个风格方向**：
1. **理性几何风**：克制、清晰、参数化、模块化、网格感
2. **光学抽象风**：黑白高对比、波纹、错觉、重复、放射、干涉
3. **生物形态抽象风**：流动、脉络、细胞、羽化、共振、生长
4. **手绘线稿风**：自由、松动、作者性、草图感、试探性笔触
5. **观念海报风**：图文一体、设计展气质、思想性、哲学感

## 提示词通用结构

```text
1. 语义理解层
   - 字面含义、情绪气质、文化联想、隐喻与张力
   - 适合的人物/物体/空间/动作关系

2. 概念转译层
   - 选择最强视觉隐喻
   - 确定 1-3 个演绎主体
   - 设计主体和文字的咬合关系

3. 版面搭建层
   - 巨型文字作为空间骨架
   - 明确承载面/地平线/平台
   - 控制主次层级：文字 > 图像叙事 > 辅助文字

4. 风格系统层
   - 2-4 色主色关系
   - 印刷纸张/版画/丝网质感
   - 极简、强概念、强识别

5. 自检层
   - 一眼有冲击、二眼能读懂、三眼觉得巧妙
   - 图与字高度咬合、没有无关装饰

6. 画面气质层（汤底之后）
   - 色彩倾向、材质质感、艺术风格
   - 情绪氛围、受众偏好、中文可读性约束
```

## 小小东提示词设计模式总结

### 三种核心模式
1. **词义可视化模式**（字体美学）：词义 → 视觉隐喻 → 巨型文字骨架
2. **知识图鉴模式**（植物图鉴）：极大主体 → 知识节点生长 → 信息层级
3. **抓拍纪实模式**（抓拍视角）：旁观视角 → 自然状态 → 真实质感

### 通用设计原则
1. **先理解，后生成**：词义理解优先于画面生成
2. **文字即结构**：巨型文字不是装饰，是空间骨架
3. **承载面必须**：有地面版强调舞台/地平线/平台
4. **信息层级清晰**：主次关系明确，留白聪明
5. **防退化自检**：不做普通插画、电商海报、廉价模板
6. **汤底+杠杆**：主体固定，末尾个性化
