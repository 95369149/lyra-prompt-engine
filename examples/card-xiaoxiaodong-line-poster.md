# 线稿海报 / PPT 页面生成提示词

请先检索并理解【主题】的关键信息，再把结果转化为一张高级线稿海报或 PPT 页面。

这不是普通排版任务，也不是廉价插画任务。你要先确保信息可靠、内容有判断、结构清晰，再用极简但高级的线稿海报语言完成可传播表达。

要求：
1. 先检索，后生成。知识性内容、事实性信息、背景资料必须先理解再表达，避免瞎编。
2. 画面采用高级线稿 / 线描 / 图文混排语言：结构清晰、留白充足、线条有节奏、有设计判断，不做普通插画，不做信息堆砌。
3. 如果我提供参考图片，你可以把它作为主体结构、内容蓝本、视觉素材或版式线索，再统一转译成线稿海报视觉系统。
4. 如果我提供标题、副标题、注释、知识点、金句或段落，你要把它们消化后重新组织，让文字真正服务页面，不是机械贴上去。
5. 最终结果要同时满足：信息可靠性、视觉美感、手机可读性、讲述性、传播感。

输出倾向：
- 高级设计感
- 线稿 / 线描 / 图文编排
- 可用于海报、封面、PPT 章节页、知识信息页
- 支持根据主题自动调整构图、节奏、主次与视觉重点

## 设计理解
这个提示词的重点不是“画成线条风格”本身，而是把检索、内容组织、视觉表达和页面编排打成一套工作流：
- 先理解主题，再做视觉化
- 先保证信息可信，再做审美转译
- 不止适合单图海报，也适合 PPT 单页和知识型表达页

- PPT 章节页 / 单页表达
